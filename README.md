## โปรเจกต์เว็บแอปพลิเคชันร้านค้าชุมชนข้างทางด้วยระบบแผนที่

เว็บแอปพลิเคชันที่ออกแบบมาเพื่อช่วยให้ผู้ใช้งานค้นหาร้านค้าริมทางและร้านค้าในชุมชนผ่านแผนที่ ระบบนี้พัฒนาขึ้นโดยใช้ภาษา PHP และฐานข้อมูล MySQL ร่วมกับ PDO เพื่อความปลอดภัยในการเข้าถึงข้อมูล อีกทั้งยังใช้ Leaflet.js และ OpenStreetMap 
ในการแสดงตำแหน่งร้านค้าและดูรายละเอียดของร้านค้า นอกจากนี้ แอปพลิเคชันยังใช้ PHPMailer เพื่อรองรับการยืนยันตัวตนด้วยรหัส OTP ผ่านทางอีเมลสำหรับการลืมรหัสผ่านบัญชีผู้ใช้งาน

หมายเหตุ: โปรเจกต์นี้จัดทำขึ้นเพื่อการศึกษาและการจัดเก็บเป็นแฟ้มสะสมผลงาน (Portfolio)

## ฟีเจอร์หลัก (Features)

**สำหรับผู้ดูแลระบบ (Admin):**

- จัดการข้อมูลผู้ใช้งาน 
- ตรวจสอบและจัดการข้อมูลร้านค้า และสินค้าทั้งหมดในระบบ
- ระบบจัดการการรายงาน (Report) แจ้งปัญหาร้านค้าจากผู้ใช้
- ดูภาพรวมของร้านค้าทั้งหมดบนแผนที่ (Map Overview)
- ระบบกระดานควบคุม (Dashboard) และดูสถิติต่างๆ

**สำหรับเจ้าของร้านค้า (Seller):**

- สมัครสมาชิกและเข้าสู่ระบบ
- ระบบลืมรหัสผ่านพร้อมยืนยันตัวตนผ่านอีเมล (Email OTP)
- สร้างและจัดการโปรไฟล์ร้านค้าของตนเอง (ระบุพิกัดบนแผนที่)
- เพิ่ม ลบ แก้ไข ข้อมูลสินค้าและรูปภาพ
- เปิด/ปิด สถานะร้านค้า (เช่น กำลังเปิดขาย, ปิดร้านชั่วคราว)
- เปิด/ปิด สถานะสินค้า (เช่น สินค้าหมด, พร้อมขาย)
- ระบบพูดคุย (Chat) กับผู้ดูแลระบบ
- ตรวจสอบรายงานปัญหาจากผู้ใช้งาน

** สำหรับผู้ใช้งานทั่วไป(Users): **

- ค้นหาร้านค้าริมทางใกล้เคียงบนแผนที่ (Interactive Map)
- สามารถเพิ่มร้านค้าเข้ายังรายการโปรด
- ดูรายละเอียดร้านค้า สินค้า 
- แจ้งรายงานปัญหา (Report) ร้านค้าที่พบปัญหา
- กดนำทางไปยังร้านค้าด้วย Google Maps

## เทคโนโลยีที่ใช้ (Tech Stack)
- Frontend: HTML5, CSS3, Bootstrap, JavaScript
- Map System: Leaflet.js (OpenStreetMap)
- Backend: PHP
- Database: MySQL
- Library: PHPMailer (สำหรับการส่ง OTP)



# วิธีการติดตั้งและรันโปรเจกต์ (Installation Setup)

เพื่อให้สามารถทดสอบโปรเจกต์นี้ในเครื่องคอมพิวเตอร์ของคุณ (Localhost) โปรดทำตามขั้นตอนดังนี้:

### 1. เตรียมความพร้อม:
ติดตั้ง XAMPP หรือโปรแกรมจำลอง Server อื่นๆ ที่รองรับ PHP และ MySQL

### 2. คัดลอกโปรเจกต์:
Clone หรือ ดาวน์โหลดโปรเจกต์นี้ไปไว้ในโฟลเดอร์ `htdocs` (สำหรับ XAMPP) เปลี่ยนชื่อโฟลเดอร์เป็น `wayside_edit` (หรือชื่อตามต้องการ) 
ตัวอย่าง path: `C:\xampp\htdocs\wayside_edit`

### 3. นำเข้าฐานข้อมูล (Database):
1. เปิด phpMyAdmin (ปกติจะอยู่ที่ http://localhost/phpmyadmin)
2. สร้างฐานข้อมูลใหม่ (ตัวอย่าง: `wayside_edit` หรือตั้งชื่อตามที่คุณใช้งาน)
3. กดที่แท็บ Import และเลือกไฟล์ SQL ของระบบ (เช่น `wayside.sql` หรือไฟล์ฐานข้อมูลของคุณ)

### 4. การตั้งค่า (Configuration):

**ตั้งค่าฐานข้อมูล (Database):**
เปลี่ยนชื่อไฟล์ `connect.example.php` เป็น `connect.php` และไฟล์ `config/connect.example.php` เป็น `config/connect.php` จากนั้นเข้าไปแก้ไขข้อมูลเชื่อมต่อฐานข้อมูลในทั้ง 2 ไฟล์:
```php
$host = "localhost";
$username = "root";
$password = "";
$db = "ชื่อฐานข้อมูลของคุณ";
```

**ตั้งค่าการส่งอีเมล (OTP สำหรับลืมรหัสผ่าน):**
เปลี่ยนชื่อไฟล์ `config/mail.example.php` เป็น `config/mail.php` แล้วเข้าไปกรอกอีเมลและ App Password ของคุณ (รหัสผ่านนี้จะไม่ถูกนำขึ้น Git):
```php
define('SMTP_USERNAME', 'your_email@gmail.com');
define('SMTP_PASSWORD', 'your_app_password_here');
```

### 5. เข้าใช้งานระบบ:
เปิดเว็บบราวเซอร์แล้วเข้าไปที่ http://localhost/wayside_edit
